## 📌 Project Overview

This project analyzes agricultural performance across different seasons, crops, environmental conditions, resource usage, irrigation methods, and economic factors.

The main purpose of this project is to identify seasonal variations, compare crop performance, study relationships between agricultural variables, and extract meaningful insights from the dataset.

---

## 🎯 Objectives

- Understand the agricultural dataset
- Clean and prepare the data for analysis
- Analyze agricultural performance across seasons
- Compare crop performance
- Study environmental and resource-related factors
- Analyze irrigation and water usage
- Examine economic performance
- Identify relationships between agricultural variables
- Perform statistical analysis
- Generate meaningful findings and recommendations

## 📈 Statistical Analysis

Correlation analysis was used to examine relationships between numerical agricultural variables.

The Kruskal-Wallis test was used to examine whether crop yield distributions differed across the three agricultural seasons.
